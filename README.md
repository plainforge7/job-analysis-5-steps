# 🍎 岗位分析五步法 · Job Analysis 5 Steps

> 🧭 用五步法把岗位说明、访谈记录或业务需求，整理为清晰的岗位画像、能力要求和可衡量的绩效结果。

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![Skill](https://img.shields.io/badge/type-SKILL-green.svg)

## ✨ 它能做什么

- 🎯 **定义岗位目的** —— 一句话说清岗位为何存在、服务谁、解决什么业务问题
- 🧩 **拆解关键职责** —— 合并为 4–8 个职责领域，标出依赖与边界
- 🧠 **提炼任职能力** —— 知识/技能、通用能力、经验、行为特征四类，附带可观察证据
- 📏 **建立绩效指标** —— 口径、周期、数据源齐全，没有基线就写「待基线确认」，不编数字
- ✅ **岗位画像与校验** —— 一致性校验：能力服务于职责，指标反映岗位目的

## 🛠️ 适用场景

| 场景 | 说明 |
| ---- | ---- |
| 🧲 招聘 | 生成真实不注水的 JD 与面试判断标准 |
| 🏗️ 定岗 | 厘清汇报线、决策权限与职责边界 |
| 🗂️ 人才盘点 | 用同一套画像横向比较同岗人员 |
| 🔧 岗位优化 | 发现职责膨胀与指标副作用，配平衡指标 |

## 📦 安装

把本仓库放入你的 skills 目录即可，例如 Kimi Work / Claude Code 的 `skills` 文件夹：

```bash
git clone https://github.com/plainforge7/job-analysis-5-steps.git
```

## 🚀 使用

把岗位相关材料（JD、访谈记录、业务需求描述）丢给 agent，说「帮我分析这个岗位」即可。skill 会默认按以下结构输出：

1. 📄 分析范围与证据
2. 🎯 岗位使命
3. 🪜 五步分析表
4. 🧩 关键职责
5. 🧠 任职能力
6. 📏 绩效指标建议
7. 🖼️ 岗位画像与判断标准
8. ⚠️ 风险与待确认问题

> 💡 只提供岗位名称也行——会先给出基于常见岗位的暂定分析，并标注需要结合公司阶段校准的部分。
